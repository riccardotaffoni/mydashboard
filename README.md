# My Dashboard

Dashboard Streamlit per visualizzare l'analisi live MTRIAGAS.

## Avvio

Installa le dipendenze:

```bash
pip install -r requirements.txt
```

Lancia la dashboard:

```bash
streamlit run live_dashboard_V2.py
```

Se vuoi avviare la versione precedente:

```bash
streamlit run live_dashboard.py
```

Streamlit aprira' automaticamente la dashboard nel browser. In alternativa, copia l'URL mostrato nel terminale.
